# Green Hours Backend 

A lightweight Express.js backend for the **Green Hours** hackathon platform. This service matches Egypt's renewable energy surplus (forecasted at locations like Benban Solar Park) with flexible industrial factory operations (e.g., cement plant grinding lines) to maximize clean energy utilization and cut carbon emissions.

---

##  Getting Started

Follow these steps to run the server locally.

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (version 16 or higher recommended).

### Installation
1. Clone or copy the project files to your directory.
2. Install the dependencies:
   ```bash
   npm.cmd install
   ```

### Running the Server
* **For Development (with Auto-reload / Nodemon):**
  ```bash
  npm run dev
  ```
* **For Production:**
  ```bash
  npm start
  ```

Once started, the backend will run at **`http://localhost:3000`**.

---

##  Using Real AI Data

To use real AI data:
 Place `DECKATHLON_modified.json` (generated by the AI teammate's Python script) in the project root.
 The backend automatically re-reads it on every request — **no restart needed**.
 If `DECKATHLON_modified.json` is missing, empty, or malformed, the server will log a warning and silently fall back to mock data, ensuring a crash-free experience during live demos.

## 📡 API Endpoints & Testing

You can use the following `curl` commands in your terminal to test the API endpoints:

### 1. Health Check
Checks if the server is up and running.
***Request:**
  ```bash
  curl http://localhost:3000/api/health
  ```
 **Expected Response:**
  ```json
  {
    "status": "ok"
  }
  ```

### 2. Check Data Source
Checks whether the server is serving real AI data or falling back to mock data.
 **Request:**
  ```bash
  curl http://localhost:3000/api/data-source
  ```
 **Expected Response:**
  ```json
  {
    "using_real_ai_data": true
  }
  ```

### 3. Renewable Forecast
Returns the hourly predicted renewable output (solar + wind). If AI data is available, it maps the AI forecast; otherwise, it falls back to the solar bell-curve.
* **Request:**
  ```bash
  curl http://localhost:3000/api/forecast
  ```
* **Expected Response:**
  ```json
  {
    "location": "Benban Solar Park, Egypt",
    "forecast": [
      { "hour": "00:00", "predicted_mw": 0 },
      ...
    ]
  }
  ```

### 4. Energy Matching Recommendation
Returns optimal green hours, dynamic recommendation text, and savings statistics.
* **Request:**
  ```bash
  curl http://localhost:3000/api/recommendation
  ```
* **Expected Response:**
  ```json
  {
    "green_hours": ["11:00", "12:00", "13:00", "14:00"],
    "recommendation_text": "Run the Grinding line from 11:00 to 14:00 instead of the current 18:00-22:00 schedule to use surplus solar power, save 22.4% on electricity cost, and avoid 27.0 tons of CO2.",
    "savings_percent": 22.4,
    "co2_saved_tons": 27.0
  }
  ```

### 5. Plant Profile Information
Returns specs about the factory's power usage profile and flexible load capacity.
* **Request:**
  ```bash
  curl http://localhost:3000/api/plant-info
  ```
* **Expected Response:**
  ```json
  {
    "plant_name": "Virtual Cement Plant (synthetic demo data)",
    "baseline_consumption_mw": 50,
    "flexible_operation": "Grinding / Milling line",
    "flexible_operation_consumption_mw": 15,
    "flexible_hours_needed": 4
  }
  ```
